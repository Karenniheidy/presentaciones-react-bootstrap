## 🛠️ ¿Cómo descargar y ejecutar cualquiera de los proyectos?

Cualquier persona puede clonar libremente este repositorio sin necesidad de permisos de acceso:

### 1. Clonar el repositorio
```bash
git clone https://github.com/Karenniheidy/presentaciones-react-bootstrap.git
```

### 2. Ejecutar un proyecto en específico (Ejemplo: `paginacionTablas`)
```bash
cd presentaciones-react-bootstrap/paginacionTablas
npm install
npm run dev
```
